# 🍽️ Cerve

Serving web applications on silver platters since C99.

This was a tiny experiment to see how easy (or hard) it is to serve web files with C99.
- It can serve HTML, CSS, JS, and the most common image files.
- File-based routing.
- You can have a custom page served on 404 errors!
- It will die the moment you try to face it with concurrent connections.
